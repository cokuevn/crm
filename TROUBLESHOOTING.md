# Решение проблем загрузки Comfort CRM

## Проблема: Очень долго грузятся данные или белый экран

Если приложение медленно загружается или показывает белый экран на некоторых устройствах, выполните следующие шаги:

### 1. Очистка кэша Service Worker

Service Worker может кэшировать старые версии приложения. Для обновления:

#### На компьютере (Chrome/Edge):
1. Откройте DevTools (F12 или Ctrl+Shift+I)
2. Перейдите на вкладку **Application** (Приложение)
3. В левом меню выберите **Service Workers**
4. Нажмите **Unregister** (Отменить регистрацию) для всех service workers
5. В левом меню выберите **Cache Storage**
6. Удалите все кэши (правый клик → Delete)
7. Закройте DevTools и обновите страницу (Ctrl+Shift+R)

#### На мобильном (Chrome Android):
1. Откройте настройки Chrome → **Конфиденциальность и безопасность**
2. Выберите **Очистить данные браузера**
3. Установите галочки на:
   - Файлы cookie и данные сайтов
   - Кэшированные изображения и файлы
4. Нажмите **Удалить данные**
5. Перезапустите браузер и откройте сайт заново

#### На iPhone (Safari):
1. Откройте **Настройки** → **Safari**
2. Прокрутите вниз и нажмите **Дополнения**
3. Выберите **Данные веб-сайтов**
4. Найдите crm-vnwl.onrender.com и удалите
5. Или нажмите **Удалить все данные веб-сайтов**
6. Вернитесь в Safari и обновите страницу

### 2. Проверка подключения к интернету

Убедитесь, что:
- ✅ Интернет-соединение стабильно
- ✅ Нет проблем с VPN или прокси
- ✅ Файрвол не блокирует доступ к https://crm-backend-1e1e.onrender.com

### 3. Жесткое обновление страницы

Попробуйте жесткое обновление:
- **Windows**: Ctrl + Shift + R или Ctrl + F5
- **Mac**: Cmd + Shift + R
- **Мобильный**: Закройте вкладку полностью и откройте заново

### 4. Проверка версии Service Worker

1. Откройте консоль браузера (F12 → Console)
2. Найдите сообщение: `🔄 Service Worker v9 initializing...`
3. Если версия меньше 9, выполните очистку кэша (шаг 1)

### 5. Проблемы только на устройстве партнера?

Если проблема только на одном устройстве:

1. **Полная очистка данных сайта** (см. шаг 1)
2. **Очистка DNS кэша**:
   - Windows: открыть CMD → `ipconfig /flushdns`
   - Mac: открыть Terminal → `sudo dscacheutil -flushcache`
3. **Перезагрузка устройства**
4. **Обновление браузера** до последней версии

### 6. Белый экран при загрузке

Если видите только белый экран:

1. Откройте консоль браузера (F12)
2. Проверьте наличие ошибок (красный текст)
3. Наиболее частые ошибки:
   - **CORS errors** → Очистите кэш Service Worker
   - **PostHog errors** → Уже исправлено в новой версии
   - **Timeout errors** → Проверьте интернет-соединение

### 7. Принудительное обновление

Если ничего не помогает:

1. Закройте все вкладки с CRM
2. Очистите все данные сайта (шаг 1)
3. Перезапустите браузер
4. Откройте сайт в **режиме инкогнито** для проверки
5. Если в инкогнито работает - проблема в кэше основного профиля

## Последние улучшения производительности (версия 9)

✅ Отключен PostHog analytics (блокировал загрузку)  
✅ Улучшен Service Worker с стратегией "Network First"  
✅ Добавлены таймауты для API запросов (30 сек)  
✅ Оптимизирован auth interceptor (быстрее на 60%)  
✅ Уменьшены задержки при повторных запросах  
✅ Добавлена обработка timeout ошибок

## Технические детали

- **Service Worker версия**: v9 (crm-cache-v9)
- **API timeout**: 30 секунд
- **Retry задержка**: 500ms (1 попытка)
- **Auth wait time**: 200ms (уменьшено с 500ms)
- **Кэш стратегия**: Network First, Cache Fallback

---

Если проблемы продолжаются после всех шагов, обратитесь к разработчику с:
1. Скриншотом консоли браузера (F12 → Console)
2. Вкладкой Network (F12 → Network) для анализа запросов
3. Информацией об устройстве и браузере
