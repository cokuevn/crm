# 📱 Гид по обновлению PWA Comfort CRM

## 🔄 Как работает автоматическое обновление

Ваше приложение **автоматически обновляется** при деплое новой версии:

1. **Service Worker проверяет обновления каждые 60 секунд**
2. При обнаружении новой версии:
   - Пользователь видит уведомление: *"Загружена новая версия приложения..."*
   - Через 2 секунды страница автоматически перезагружается
   - Загружается свежая версия с очищенным кэшем

## 📝 Как выпустить новую версию

### Вариант 1: Автоматический (рекомендуется)

**Windows:**
```bash
update-version.bat "Исправлена смена статуса платежей"
git add .
git commit -m "Update PWA to v5: Исправлена смена статуса платежей"
git push
```

**Linux/Mac:**
```bash
chmod +x update-version.sh
./update-version.sh "Исправлена смена статуса платежей"
git add .
git commit -m "Update PWA to v5: Исправлена смена статуса платежей"
git push
```

### Вариант 2: Вручную

1. Откройте `frontend/public/sw.js`
2. Найдите строку:
   ```javascript
   const CACHE_NAME = 'crm-cache-v4';
   ```
3. Увеличьте версию:
   ```javascript
   const CACHE_NAME = 'crm-cache-v5';
   ```
4. Обновите комментарий с описанием:
   ```javascript
   const CACHE_NAME = 'crm-cache-v5'; // Обновлено: v5 - Исправлена смена статуса платежей
   ```
5. Коммит и пуш:
   ```bash
   git add frontend/public/sw.js
   git commit -m "Update PWA to v5: Исправлена смена статуса платежей"
   git push
   ```

## ⏱️ Таймлайн обновления

| Время | Что происходит |
|-------|---------------|
| 0 сек | Вы делаете `git push` |
| ~2 мин | Render деплоит новую версию |
| +0-60 сек | Service Worker пользователя обнаруживает обновление |
| +2 сек | Приложение автоматически перезагружается |

**Итого:** Пользователи получают обновление через **2-3 минуты** после деплоя.

## 🎯 Best Practices

### ✅ DO:
- Увеличивайте версию при каждом деплое с изменениями UI/логики
- Пишите понятные описания изменений в комментарии
- Тестируйте на staging перед production

### ❌ DON'T:
- Не забывайте увеличивать версию (иначе пользователи не получат обновление)
- Не делайте breaking changes без предупреждения
- Не пропускайте версии (v4 → v6)

## 🧪 Как проверить, что обновление работает

### Способ 1: DevTools
1. Откройте приложение в Chrome
2. F12 → Application → Service Workers
3. Нажмите "Update" → обновление должно сработать

### Способ 2: Консоль
1. F12 → Console
2. Должно появиться:
   ```
   New version available! Reloading...
   ```

### Способ 3: Реальный тест
1. Задеплойте новую версию
2. Откройте приложение на телефоне
3. Подождите до 60 секунд
4. Должно появиться уведомление и автоперезагрузка

## 🆘 Troubleshooting

### Пользователь не получает обновление?
1. Проверьте, увеличили ли версию в `sw.js`
2. Проверьте, задеплоена ли новая версия на Render
3. Попросите пользователя обновить вручную (Ctrl+Shift+R)
4. Проверьте консоль браузера на ошибки

### Service Worker не регистрируется?
1. Убедитесь, что сайт работает по HTTPS
2. Проверьте, что `sw.js` доступен по адресу `/sw.js`
3. Проверьте консоль на ошибки CORS

### Старая версия всё ещё кэшируется?
1. Application → Clear storage → Clear site data
2. Или пересоберите приложение:
   ```bash
   npm run build
   ```
