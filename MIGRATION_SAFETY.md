# 🛡️ Безопасность Миграции - Гарантия Сохранности Данных

## ❓ Почему Миграция БЕЗОПАСНА

### Что НЕ изменяется:
- ❌ НЕ удаляются существующие коллекции
- ❌ НЕ удаляются документы
- ❌ НЕ изменяются критичные данные (суммы, даты, графики платежей)
- ❌ НЕ удаляются пользователи
- ❌ НЕ изменяются капиталы (балансы остаются)
- ❌ НЕ изменяются клиенты (долги, платежи остаются)

### Что ДОБАВЛЯЕТСЯ:
- ✅ Новая коллекция `organizations` (новая, не влияет на старые)
- ✅ Новая коллекция `organization_members` (новая, не влияет на старые)
- ✅ Новая коллекция `tasks` (новая, не влияет на старые)
- ✅ К капиталам добавляется поле `organization_id` (старое `owner_id` ОСТАЕТСЯ!)
- ✅ К клиентам добавляется поле `organization_id` (все остальное ОСТАЕТСЯ!)

**ВАЖНО:** Миграция только ДОБАВЛЯЕТ поля, НЕ удаляет и НЕ изменяет существующие!

- ✅ Создает ТОЛЬКО организации

## 🔄 Как Откатить Изменения (Если Что-то Пойдет Не Так)

### Вариант 1: Удалить Только Новые Коллекции

```python
# rollback.py
import asyncio
from motor.motor_asyncio import AsyncIOMotorClient
import os
from dotenv import load_dotenv
import certifi

load_dotenv()

async def rollback():
    mongo_url = os.environ['MONGO_URL']
    client = AsyncIOMotorClient(mongo_url, tls=True, tlsCAFile=certifi.where())
    db = client[os.environ['DB_NAME']]
    
    # Удалить ТОЛЬКО новые коллекции
    await db.organizations.drop()
    await db.organization_members.drop()
    await db.tasks.drop()
    await db.activity_logs.drop()
    
    print("✓ Новые коллекции удалены")
    print("✓ Ваши данные (capitals, clients) не тронуты")
    
    client.close()

asyncio.run(rollback())
```

### Вариант 2: Удалить Добавленные Поля

```python
# remove_new_fields.py
import asyncio
from motor.motor_asyncio import AsyncIOMotorClient
import os
from dotenv import load_dotenv
import certifi

load_dotenv()

async def remove_fields():
    mongo_url = os.environ['MONGO_URL']
    client = AsyncIOMotorClient(mongo_url, tls=True, tlsCAFile=certifi.where())
    db = client[os.environ['DB_NAME']]
    
    # Удалить новые поля из капиталов
    await db.capitals.update_many(
        {},
        {"$unset": {
            "organization_id": "",
            "restricted_access": "",
            "allowed_users": ""
        }}
    )
    
    # Удалить новые поля из клиентов
    await db.clients.update_many(
        {},
        {"$unset": {
            "organization_id": "",
            "assigned_to": "",
            "assigned_at": "",
            "assigned_by": "",
            "activity_log": "",
            "tags": "",
            "notes": ""
        }}
    )
    
    print("✓ Новые поля удалены из capitals и clients")
    
    client.close()

asyncio.run(remove_fields())
```

## 🎯 Альтернатива: Работа БЕЗ Миграции

3. Заполните форму

**Что произойдет:**
- Создастся новая организация
- Вы будете владельцем
- Можно добавлять менеджеров
- Можно создавать задачи

**Минусы:**
- Менеджеры не увидят ваших старых капиталов и клиентов
- Нужно будет создавать новые капиталы в этой организации

## 📊 Что Реально Меняется При Миграции

### Было (до миграции):

```javascript
// Коллекция capitals
{
  "id": "capital-123",
  "name": "Основной капитал",
  "owner_id": "cokuevn@gmail.com",
  "balance": 150000
}

// Коллекция clients
{
  "client_id": "client-456",
  "capital_id": "capital-123",
  "name": "Иванов Иван",
  "debt_amount": 50000
}
```

### Станет (после миграции):

```javascript
// Коллекция capitals (добавлено 1 поле)
{
  "id": "capital-123",
  "name": "Основной капитал",
  "owner_id": "cokuevn@gmail.com",  // ← ОСТАЕТСЯ!
  "organization_id": "org-789",      // ← ДОБАВЛЕНО
  "balance": 150000                  // ← НЕ МЕНЯЕТСЯ!
}

// Коллекция clients (добавлено несколько полей)
{
  "client_id": "client-456",
  "capital_id": "capital-123",
  "name": "Иванов Иван",
  "debt_amount": 50000,              // ← НЕ МЕНЯЕТСЯ!
  "organization_id": "org-789",      // ← ДОБАВЛЕНО
  "assigned_to": null,               // ← ДОБАВЛЕНО (null = никому не назначен)
  "activity_log": [],                // ← ДОБАВЛЕНО (пустой массив)
  "tags": [],                        // ← ДОБАВЛЕНО (пустой массив)
  "notes": null                      // ← ДОБАВЛЕНО (пусто)
}
```

**Видите?** Все ваши важные данные (баланс, долги, графики) НЕ меняются!
