# Развертывание обновлений Comfort CRM

## Быстрая инструкция по деплою

### 1. Развертывание Frontend на Render

После внесения изменений в код:

```bash
# 1. Убедитесь, что все изменения сохранены
git status

# 2. Добавьте файлы в git
git add .

# 3. Сделайте коммит с описанием изменений
git commit -m "Оптимизация загрузки: убран PostHog, улучшен Service Worker v9"

# 4. Отправьте на GitHub
git push origin main
```

**Render автоматически**: 
- Обнаружит изменения в репозитории
- Запустит сборку `npm run build`
- Развернет новую версию

⏱️ **Время деплоя**: ~3-5 минут

### 2. Проверка развертывания

После деплоя проверьте:

1. Откройте https://crm-vnwl.onrender.com
2. Откройте консоль браузера (F12)
3. Проверьте версию SW: должно быть `Service Worker v9 initializing...`
4. Проверьте отсутствие PostHog ошибок

### 3. Очистка кэша на клиентах

**ВАЖНО**: После обновления пользователи должны очистить кэш!

Отправьте партнеру инструкцию из файла `TROUBLESHOOTING.md` (раздел 1).

Или просто попросите:
1. Закрыть все вкладки с CRM
2. Открыть настройки браузера → Очистить данные
3. Обновить страницу с Ctrl+Shift+R

### 4. Автоматическое обновление

Service Worker настроен на автообновление:
- Проверяет обновления каждые 60 секунд
- Показывает уведомление "Загружена новая версия"
- Автоматически перезагружает через 2 секунды

## Мониторинг после деплоя

### Проверка логов Render

1. Перейдите на https://dashboard.render.com
2. Выберите сервис `crm-vnwl`
3. Откройте вкладку **Logs**
4. Проверьте наличие ошибок при сборке

### Проверка работоспособности

```bash
# Проверка API
curl https://crm-backend-1e1e.onrender.com/api/ping

# Должен вернуть: {"status":"ok"}
```

### Если что-то пошло не так

**Откат к предыдущей версии:**

1. Зайдите в Render Dashboard
2. Выберите сервис
3. Events → найдите предыдущий успешный деплой
4. Нажмите "Redeploy"

**Или через Git:**

```bash
# Найти предыдущий коммит
git log --oneline

# Откатиться
git revert HEAD

# Отправить
git push origin main
```
