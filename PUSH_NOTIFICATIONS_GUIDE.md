# 🔔 Руководство по Push-уведомлениям Comfort CRM

## 📱 Что добавлено

### 1. Кнопки в мобильном меню (☰):

✅ **"Установить приложение"** (показывается только если не установлено)
- Синяя градиентная кнопка
- Мгновенная установка PWA

✅ **"Включить уведомления"** 
- Запрашивает разрешение на уведомления
- После включения меняет цвет на зелёный
- Показывает тестовое уведомление
- **Регистрирует фоновую синхронизацию** (для работы при закрытом приложении)

✅ **"Проверить обновления"**
- Принудительная проверка новой версии
- Иконка вращается при проверке

### 2. Автоматические уведомления о платежах:

🔔 **Когда отправляются:**

**А) При открытом приложении:**
- При каждой загрузке Dashboard
- Мгновенно

**Б) При закрытом приложении (фоновый режим):**
- **Каждые 12 часов** (автоматически)
- Только на **Android Chrome/Edge** (ограничение браузеров)
- Только если приложение **установлено как PWA**

🎯 **О чём уведомляют:**
- **Платежи сегодня**: "💰 Платёж сегодня!"
- **Платежи завтра**: "⏰ Платёж завтра"

📝 **Содержание уведомления:**
```
💰 Платёж сегодня!
Иванов Иван Иванович
12,500₽
```

## ⚠️ Важные ограничения браузеров

| Платформа | Фоновые уведомления | Примечание |
|-----------|---------------------|------------|
| **Android (Chrome/Edge)** | ✅ Да | Работает идеально с Periodic Background Sync |
| **Android (Firefox)** | ❌ Нет | Только при открытом приложении |
| **iOS (Safari)** | ❌ Нет | Apple не поддерживает фоновые push (требует APNs) |
| **Desktop (Chrome/Edge)** | ⚠️ Частично | Работает, если приложение в фоне |
| **Desktop (Firefox)** | ❌ Нет | Только при открытом приложении |

## 🚀 Как работает

### Для пользователя:

1. **Первый вход в приложение**
   - Через 3 секунды появляется баннер "Установить Comfort CRM"
   - Пользователь нажимает "Установить"
   - Приложение добавляется на главный экран

2. **Включение уведомлений**
   - Меню (☰) → "Включить уведомления"
   - Браузер запрашивает разрешение
   - Появляется тестовое уведомление
   - Кнопка становится зелёной

3. **Получение уведомлений**
   - Пользователь открывает Dashboard
   - Если есть платежи сегодня/завтра → отправляются уведомления
   - Клик по уведомлению → открывает приложение

### Для разработчика:

```javascript
// Отправка уведомления вручную
import notificationService from '../services/notificationService';

// Проверка разрешения
const permission = notificationService.checkPermission();
// 'granted' | 'denied' | 'default' | 'unsupported'

// Запрос разрешения
const granted = await notificationService.requestPermission();

// Отправка уведомления
await notificationService.showNotification('Заголовок', {
  body: 'Текст уведомления',
  icon: '/icon.svg',
  badge: '/icon.svg',
});

// Автоматические уведомления о платежах
await notificationService.checkAndNotify(dashboardData);
```

## ⚙️ Настройки

### Частота проверки (в `notificationService.js`):

Сейчас уведомления отправляются **при каждой загрузке Dashboard**.

Если нужно ограничить частоту:

```javascript
// Добавить в localStorage метку времени последнего уведомления
const lastNotified = localStorage.getItem('lastNotificationTime');
const now = Date.now();
const ONE_HOUR = 60 * 60 * 1000;

if (!lastNotified || now - parseInt(lastNotified) > ONE_HOUR) {
  await notificationService.checkAndNotify(data);
  localStorage.setItem('lastNotificationTime', now.toString());
}
```

### Типы уведомлений:

Можно добавить уведомления для:
- ❌ Просроченных платежей
- ✅ Успешных оплат
- 📊 Еженедельные отчёты
- 💰 Достижение целей по сбору

## 🧪 Тестирование

### Проверка на Android/iOS:

1. Откройте приложение
2. Меню → "Включить уведомления"
3. Разрешите уведомления
4. Должно появиться тестовое уведомление
5. Зайдите в Dashboard → если есть платежи сегодня/завтра, придут уведомления

### Проверка на Desktop (Chrome):

1. Откройте приложение
2. Меню (или F12 → Application → Notifications)
3. Включите уведомления
4. Тестовое уведомление должно появиться в правом нижнем углу

## 🔒 Безопасность и приватность

- ✅ Уведомления отправляются только локально (без серверов)
- ✅ Данные не передаются третьим лицам
- ✅ Пользователь может отключить в любой момент (настройки браузера)
- ✅ Работает только при открытом приложении или в фоне (если установлено)

## 🐛 Troubleshooting

### Уведомления не приходят?

1. Проверьте разрешения в настройках браузера
2. Проверьте, что Service Worker зарегистрирован (F12 → Application → Service Workers)
3. Проверьте консоль на ошибки
4. Попробуйте переустановить приложение

### Кнопка "Установить приложение" не появляется?

- На iOS: используйте Safari → Поделиться → На экран "Домой"
- На Android: кнопка появится автоматически в Chrome
- На Desktop: иконка в адресной строке Chrome

## 🎨 Кастомизация уведомлений

### Изменить звук вибрации:

```javascript
vibrate: [200, 100, 200] // Короткая-пауза-короткая
vibrate: [500] // Одна длинная
vibrate: [200, 100, 200, 100, 200] // Несколько коротких
```

### Изменить приоритет:

```javascript
requireInteraction: true // Уведомление не исчезает автоматически
requireInteraction: false // Исчезает через несколько секунд
```

### Добавить действия:

```javascript
actions: [
  { action: 'view', title: 'Посмотреть', icon: '/icons/view.png' },
  { action: 'dismiss', title: 'Закрыть', icon: '/icons/close.png' },
  { action: 'mark-paid', title: 'Отметить оплаченным', icon: '/icons/check.png' }
]
```
