## 📋 Пошаговая Инструкция

### Шаг 1: Миграция Данных (ОБЯЗАТЕЛЬНО!)

```bash
# В корне проекта
python migrate_to_organizations.py
```

**Что делает миграция:**
- Создает организацию для каждого владельца капиталов
- Обновляет капиталы (добавляет `organization_id`)
- Обновляет клиентов (добавляет `organization_id` и новые поля)
- Создает членство с ролью `owner`

**Ожидаемый вывод:**
```
=== Starting Migration to Organizations ===

Step 1: Creating organizations for existing users...
  ✓ Created organization for: cokuevn@gmail.com

Step 2: Migrating capitals to organizations...
Обновлено капиталов: 2

Step 3: Migrating clients to organizations...
Обновлено клиентов: 15

=== Migration Complete ===
```

### Шаг 2: Запустить Backend

```bash
cd backend
python server.py
```

**Проверка:**
- Backend должен запуститься на `http://localhost:8000`
- Откройте `http://localhost:8000/docs` - должна открыться Swagger документация
- Проверьте новые endpoints:
  - `/api/organizations/my`
  - `/api/tasks`
  - `/api/organizations/{org_id}/members`

### Шаг 3: Запустить Frontend

```bash
cd frontend
npm start
```

**Проверка:**
- Frontend должен запуститься на `http://localhost:3000`
- Должна открыться страница входа

## 🎯 Тестирование Функционала

### 1. Войти в Систему

1. Откройте `http://localhost:3000`
2. Войдите под своим аккаунтом (например, `cokuevn@gmail.com`)

### 2. Проверить Организации

1. **В навигации** кликните на кнопку "**Организации**"
2. Вы должны увидеть свою организацию (созданную при миграции)
3. Попробуйте создать новую организацию:
   - Нажмите "+ Создать организацию"
   - Заполните форму
   - Сохраните

### 3. Добавить Менеджера

1. На странице организаций, кликните "**Менеджеры**"
2. Нажмите "+ Пригласить менеджера"
3. Заполните форму:
   - Email: `manager@test.com`
   - Роль: "Менеджер"
   - Отдел: "Работа с просрочками"
   - Должность: "Менеджер по просрочкам"
4. Сохраните

**Результат:**
- Менеджер добавлен в список
- Видны его данные: email, роль, отдел, разрешения

### 4. Создать Задачу

1. **В навигации** кликните на кнопку "**Задачи**"
2. Нажмите "+ Создать задачу"
3. Заполните форму:
   - Название: "Обработать просрочки за январь"
   - Описание: "Связаться со всеми клиентами с просрочкой"
   - Тип: "Работа с просрочками"
   - Приоритет: "Высокий"
   - Назначить: выберите менеджера
   - Срок: выберите дату
4. Сохраните

**Результат:**
- Задача появилась в списке
- Видны детали: название, статус, приоритет, назначенный менеджер

### 5. Работа с Задачей

1. Кликните на задачу в списке
2. Откроется модальное окно с деталями
3. Попробуйте:
   - Добавить комментарий
   - Изменить статус (если вы назначены)
   - Завершить задачу (если статус "В работе")

## 🐛 Решение Проблем

### Проблема 1: "Организации не найдены"

**Причина:** Не выполнена миграция

**Решение:**
```bash
python migrate_to_organizations.py
```

### Проблема 2: "403 Forbidden" при создании менеджера

**Причина:** У пользователя нет прав

**Решение:**
- Проверьте, что вы владелец организации (роль `owner`)
- Перезапустите frontend, чтобы обновить токен

### Проблема 3: Страницы "Организации" или "Задачи" не открываются

**Причина:** Не обновлен код frontend

**Решение:**
1. Проверьте, что файлы созданы:
   - `frontend/src/pages/Organizations.js`
   - `frontend/src/pages/OrganizationMembers.js`
   - `frontend/src/pages/Tasks.js`
2. Перезапустите `npm start`

### Проблема 4: CORS ошибки

**Причина:** Backend не настроен для CORS

**Решение:**
Убедитесь, что в `backend/server.py` есть:
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["GET", "POST", "PUT", "DELETE", "OPTIONS"],
    allow_headers=["*"],
)
```

### Проблема 5: "Cannot find module organizationService"

**Причина:** Не создан файл сервиса

**Решение:**
Проверьте наличие файла:
```bash
ls frontend/src/lib/services/organizationService.js
```

Если файла нет - он должен быть в проекте, пересоздайте его.
