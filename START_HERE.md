## 💡 Примеры Использования

### Пример 1: Добавить Менеджера

```bash
curl -X POST "http://localhost:8000/api/organizations/{org_id}/members" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "X-Organization-ID: {org_id}" \
  -H "Content-Type: application/json" \
  -d '{
    "user_email": "manager@company.com",
    "role": "manager",
    "department": "collections",
    "permissions": [
      "clients.view_all",
      "clients.edit",
      "payments.create"
    ]
  }'
```

### Пример 2: Создать Задачу

```bash
curl -X POST "http://localhost:8000/api/tasks" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "X-Organization-ID: {org_id}" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Обработать просрочки",
    "type": "collection",
    "priority": "high",
    "assigned_to": "manager_user_id",
    "client_filters": {"status": "overdue"}
  }'
```

### Пример 3: Получить Мои Задачи

```bash
curl -X GET "http://localhost:8000/api/tasks?assigned_to_me=true" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "X-Organization-ID: {org_id}"
```

## 🎓 Основные Концепции

### Организация
Представляет вашу компанию. Все данные (капиталы, клиенты) привязаны к организации.

### Члены Организации
Люди, работающие в организации: владельцы, админы, менеджеры.

### Роли
- **Owner** (Владелец) - полный доступ
- **Admin** (Администратор) - почти полный доступ
- **Manager** (Менеджер) - ограниченный доступ к назначенным клиентам
- **Viewer** (Наблюдатель) - только просмотр

### Задачи
Задания для менеджеров с автоматическим назначением клиентов по фильтрам.

### Разрешения
Детальный контроль доступа (например, `clients.view`, `payments.create`).

## ❓ Часто Задаваемые Вопросы

### Q: Нужно ли менять существующий код?
**A:** Нет! Старые endpoints продолжают работать. Новая система полностью обратно совместима.

### Q: Что произойдет с существующими данными?
**A:** Скрипт миграции автоматически:
- Создаст организацию для каждого владельца
- Обновит капиталы и клиентов
- Сохранит все данные

### Q: Как менеджер получит доступ?
**A:** 
1. Админ приглашает менеджера через API
2. Менеджер регистрируется в Firebase с указанным email
3. Автоматически получает доступ с назначенными правами

### Q: Можно ли изменить разрешения менеджера?
**A:** Да! Используйте `PUT /api/organizations/{org_id}/members/{member_id}`

### Q: Как назначить клиентов менеджеру?
**A:** Создайте задачу с фильтрами - клиенты назначатся автоматически!
